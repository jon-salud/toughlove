# Toughlove Guide Skill

This skill provides context and guidelines for working on the Toughlove New Zealand repository.

## Instructions
1.  **Read the Guide**: Always refer to `Gemini.md` in the root directory for the latest project structure, tech stack details, and conventions.
2.  **Context Awareness**: Be aware that there is a `legacy_site` directory which serves as a reference but should not be modified unless explicitly requested. The active development happens in `toughlove-web`.
3.  **Socials**: The official Facebook page is https://www.facebook.com/ToughLove.org.nz/.
