# Toughlove Repository Guide for AI Assistants

## Overview
This repository hosts the source code for the Toughlove New Zealand website. The project is a renovation of an existing site, aiming to modernize the web presence of the non-profit organization.

## Tech Stack
- **Frontend Framework**: React (via Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages
- **Package Manager**: npm

## Project Structure
- `toughlove-web/`: The main directory for the modern React application.
    - `src/`: Source code.
        - `components/`: Reusable UI components.
        - `pages/`: Page components for routing.
    - `vite.config.ts`: Vite configuration.
- `legacy_site/`: Contains the old website files for reference.

## Key Conventions
- **Commands**: Run all `npm` commands from the `toughlove-web` directory.
- **Styling**: Prefer Tailwind CSS utility classes over custom CSS.
- **Routing**: Uses `react-router-dom`.
